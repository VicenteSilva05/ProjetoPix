# ProjetoPix

## Trabalho da Disciplina de Gerência de Configuração — UFC Quixadá

## 📋 Sobre o projeto

O sistema simula as operações básicas de um banco integradas ao PIX: cadastro de usuários, contas bancárias e chaves PIX, além de transferências e recebimentos de valores entre contas.

## Funcionalidades — Entrega 1

- [ ] Cadastrar Usuário
- [ ] Atualizar Dados do Usuário
- [ ] Remover Usuário
- [ ] Criar Conta Bancária
- [ ] Atualizar Dados da Conta
- [ ] Remover Conta Bancária
- [ ] Receber Valor em Conta usando PIX
- [ ] Transferir Valor Entre Contas usando PIX
- [ ] Gerar Chave PIX Aleatória
- [ ] Validar Chave PIX (CPF, CNPJ, Email ou Telefone)
- [ ] Associar chave PIX (CPF, CNPJ, Email ou Telefone) a uma
  conta
